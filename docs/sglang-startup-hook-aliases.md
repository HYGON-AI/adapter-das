# SGLang Hook 别名传播启动优化

SGLang 为每个 Hook 扫描所有已加载模块的命名空间，以更新早先通过
`from ... import ...` 保留的别名。大量 Hook 与模块组合时，这段 Python
循环成为启动 CPU 热点。Adapter 提供同语义的 CPython CPU 原生扫描（默认启用），
不修改官方 SGLang 源码文件，也不改变模型数学或 Hook 顺序。

## 使用与回退

默认启用原生扫描（`HCU_HOOK_ALIAS_FAST=1`）。恢复官方全量扫描使用值 `0`，或在
配置文件中选择 `ops: {hook_alias_propagation: stock}`。目录状态：`fast` 为
production（默认），`stock` 为 validated（回退路径）。

加速仅支持 Linux CPython、启用 GIL、Python 头文件和可用 C 编译器。
先核对官方 `_propagate_patch` 签名及源码 SHA256；不支持的版本或缺少构建条件
保留官方路径。当前匹配源码 SHA256 为
`49c03f76266054fb81be18c81c89419c60716d79bf7857729c2aff0e762d5e61`。
不要仅因函数同名就放宽源码校验；升级时须重新核对语义与回归。

辅助扩展只依赖 Python C API，不链接 Torch/HIP。内容寻址缓存位于
`~/.cache/hcu_adapter/hook_aliases`，键包含实现源码、Python ABI、平台和
编译器身份；文件锁及原子发布避免并发读取半成品。已存在缓存损坏时显式报错，
不把完整性错误伪装为正常回退。

每次调用重新获取模块列表快照，不维护可能过期的别名索引。保留源模块排除、
对象身份比较、自定义模块 getter/setter、命名空间协议和原异常边界。
非原生支持的对象保留官方扫描；运行时注册项为 `hook_alias_propagation`。
首次启动可能需要编译，暖缓存收益不能外推为首次编译耗时。

## 验证与证据边界

测试见 `tests/adapter/test_hook_aliases.py`；完整插件接线独立核对的固定组合
为 681 个目标、681 个应用、0 个跳过，优化前后集合一致。约 10049 个模块、
20 次传播的局部微基准中位值为 0.6421 → 0.0638 秒；
独立完整插件加载阶段为 36.74 → 10.25 秒。这些不是整服务倍数。

2026-11-25 在 S9、BW1101/gfx938 八卡，以 GLM5.2 Channel FP8 W8A8、
TP8/EP8、attn-cp-size=8、enable_prefill_cp=False，使用相同容器和本地模型，
进行了未优化/优化交替各三次成功启动：

| 组合 | 第1次/秒 | 第2次/秒 | 第3次/秒 | 平均/秒 |
|---|---:|---:|---:|---:|
| 原现场组合 | 389.48 | 265.69 | 244.33 | 299.84 |
| 延后环境摘要探测 + 原生 Hook 扫描 | 280.60 | 202.43 | 208.32 | 230.45 |

总耗时平均减少 69.39 秒（23.14%）；权重加载前为 142.00 → 86.67 秒。
没有清系统缓存，原生辅助扩展已预热，健康检查轮询为 3 秒。权重处理也有
波动，因此不能将全部收益归于本 PR 或保证其他模型有相同幅度。

其中环境摘要延后探测已经由上游 `d715496`（PR #162）提供；
**上述整模型结果是此前两项组合的证据，不是基于本 PR 最新基点、单独隔离
Hook 扫描收益的 3 次 A/B**。迁移到最新分支后的检查结果单独记录于 PR，
不追认历史测试为新基点的整模型验收。

第三次未优化首次尝试收到 SIGKILL，节点同期出现 HCU reset，设备一度不可用；
触发原因未确认，未发现 OOM 证据。设备恢复并通过八卡基础运算检查后补测
最后一组。失败尝试单独保留，不计入成功启动平均值；不能称六次尝试全部成功。
六次成功样本的 128/1024/4096 token 固定输入各输出 64 token，
输出文本、token ID、结束原因完全一致，简单问答均正常。未重跑三套精度数据集，
也未验证其他模型，不外推为完整精度或全模型兼容证明。

原始记录保留在 S9：
`results/startup-opt-3x-20261125-141715`（逐次日志、源码校验、汇总、失败及恢复记录），
以及 `results/startup-opt-20261125-101913`（CPU 回归、微基准、完整 Hook 核对）。
