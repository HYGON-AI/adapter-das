估算口径（假设与公式）
    
    
      
  • 参数量：GQA（q/kv/o）或 MLA（q_a 复制，q_b/kv_b/o 按 TP 切）；dense FFN 3·h·inter；MoE = E·3·h·moe_inter（EP≤TP 时每卡总量 = E·3·h·mi/TP，tp=ep 即整专家分布；first_k_dense_replace 前层按 dense 算）；shared expert 按 TP 切。tie_word_embeddings 决定 lm_head 是否单份。
    • 
      
  • 字节/参数：bf16/fp16=2；fp8≈1.05（含 scale/元数据）；int8≈1.05；int4(AWQ/GPTQ/slimquant, g128)≈0.5625；embedding 按底模 dtype（量化模型的 embed 常驻高精度）。
    • 
      
  • 切分：embedding/lm_head/dense FFN/MoE 按 TP；attention 按 TP（开 dp-attention 时按 TP/DP——attention 复制 DP 份）；CP 不切权重（只切序列/KV）。
    • 
      
  • 不含：KV cache、激活、CUDA graph 池、NCCL/通信 buffer；DeepEP low_latency 的 HIPC 运行时双份专家权重（②里已提示 mem 0.60）；MTP draft 权重（约 1 层 + lm_head）。
    • 
      
  • GDN/线性注意力（Qwen3.5/3.6 混合）结构未建模——解析到时给出警告，可用"其他/层"输入手补。
